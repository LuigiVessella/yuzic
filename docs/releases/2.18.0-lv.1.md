# Yuzic Test 2.18.0-lv.1

## Changes

- Studio updates the Home, album and artist layouts and the mini player.
- Playback retains the queue and listening position during connection loss, with an explicit retry.
- The seek bar and mini-player progress use transform animations. Scrubbing updates the timestamps only when the displayed time changes.
- Downloader queues retain their latest snapshot during failures, back off independently and batch catalog scans.
- Unified search shows the progress and failure of each external source and can retry it individually.

## Validation

- Typed routes, TypeScript, lint on changed source files, the architecture checks and 128 focused Jest tests passed.
- The signed Android ARM64 test APK was built and verified with version code 57.
- Android device validation and profiling are pending.
